# Support

## Usage questions

For self-hosting, setup, provider integration, or expected behavior:

1. check [README.md](./README.md);
2. check [docs/TROUBLESHOOTING.md](./docs/TROUBLESHOOTING.md);
3. search existing Issues/Discussions;
4. open a new support/question issue if the answer is not already documented.

When asking for help, include:

- Node/npm versions;
- operating system;
- relevant command;
- sanitized error code/message;
- whether the issue affects web, server, Supabase, GPT Actions, or a provider;
- exact validation already attempted.

Never paste real API keys, bearer tokens, `.env` files, or service-role credentials.

## Bugs

A bug report should contain:

- current behavior;
- expected behavior;
- minimal reproduction;
- logs with secrets removed;
- relevant commit/version.

## Security issues

Do not use normal support channels for vulnerabilities.

Follow [SECURITY.md](./SECURITY.md).

## Hosted commercial service

This source repository does not itself define an SLA, billing support policy, refund policy, or hosted-service support commitment. Those belong to the operator of a hosted MCP Gateway deployment.
